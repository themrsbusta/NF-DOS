# Source status

The default branch restores the identified NF-DOS core, upstream sources and patches from the previous main branch. The v6.0 release assets and tag remain unchanged.

Additional source and build material was recovered separately: final-candidate FORMAT and SRDISK snapshots, floppy build tools, NFLLM 1.2, the 7-Zip DOS port, and other CD components. This material is not yet fully imported or audited for redistribution and source-to-binary correspondence. Independent applications retain their own identity and licenses.

The recovered inventory identifies missing historical boot-sector source and the V22 base image, missing CD ISO generation script, and incomplete source availability for DosView, Mpxplay, mTCP and toolchains. A reproducible end-to-end build is not established. See DISTRIBUTION-COMPLIANCE.md for the existing technical review. No new build or test is claimed.
